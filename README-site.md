# Fryday — сайт предзаказа

Статический сайт без сборки: HTML, CSS, JavaScript. Заливается в Cloudflare Pages как есть.

## Что в папке

| Файл | Назначение |
| --- | --- |
| `index.html` | Лендинг: герой, о нас, меню, топпинги, адрес и часы, связаться |
| `order.html` | Предзаказ: меню, корзина, оформление, экран подтверждения |
| `faq.html` | Вопросы и ответы |
| `privacy.html` | Политика конфиденциальности |
| `css/style.css` | Все стили (цвета бренда в начале файла) |
| `js/config.js` | **Единственный файл, который нужно заполнить** |
| `js/menu.js` | Загрузка меню, кэш на 10 минут, запасное меню, общие функции |
| `js/order.js` | Корзина, время, телефон, отправка заказа, подтверждение |
| `js/landing.js` | Лендинг, FAQ и политика: подставляет данные из config.js и меню |
| `data/menu-fallback.json` | Запасная копия меню на случай, если таблица недоступна |
| `img/items/`, `img/brand/` | Готовые фото и логотип — положите сюда свои файлы |

## Запуск за 5 шагов

1. Положите готовые фото в `img/items/` и логотипы в `img/brand/` (имена — как в ТЗ, §15).
2. Заполните `js/config.js` — все строки с `"ВСТАВЬТЕ_СЮДА"` (см. ниже).
3. В `index.html` и `order.html` замените `og:image` на полный адрес после публикации, например `https://fryday.pages.dev/img/brand/logo-512.png` — иначе в WhatsApp не будет картинки в превью ссылки.
4. Проверьте ответ «Как оплатить?» в `faq.html` — впишите свои способы оплаты.
5. Cloudflare Pages → Create project → Direct upload → перетащите папку `fryday-site`. Сборка не нужна.

## Что заполнить в `js/config.js`

- `API_URL` — адрес веб-приложения Apps Script (заканчивается на `/exec`).
- `TURNSTILE_SITE_KEY` — публичный ключ Turnstile; домен сайта должен быть в списке виджета.
- `WA_PHONE` — номер WhatsApp цифрами, без `+`: `996XXXXXXXXX`.
- `ADDRESS` — адрес для людей.
- `PHONE_DISPLAY` — телефон для звонков, например `+996 705 515 151`.
- `INSTAGRAM_URL` — ссылка на профиль.
- `MAP_URL` — ссылка «Поделиться» из 2ГИС или Google Maps.
- `HOURS_TEXT` — необязательно: если оставить как есть, часы берутся из таблицы.

Пока значение не заполнено, соответствующий блок на сайте просто скрыт.

## Как меню попадает на сайт

Сайт запрашивает `API_URL?action=menu`. Ответ хранится на телефоне 10 минут. Если таблица недоступна, показывается последняя сохранённая копия или `data/menu-fallback.json` с пометкой «цены могут быть неактуальны».

Новая позиция в таблице появляется на сайте сама. Фото для неё: положите `img/items/<id>.webp` (id — как в таблице) или впишите ссылку в колонку `photo`. Если фото нет — показывается нейтральная заглушка.

Меняете цены — обновите и `data/menu-fallback.json`, чтобы запасная копия не устаревала.

## Важные решения

- Заказ отправляется как `text/plain`, чтобы Apps Script не получал CORS-preflight.
- `clientKey` создаётся один раз на корзину и повторяется при каждой повторной отправке — двойное нажатие или повтор после обрыва связи не создают второй заказ. Если корзину изменили после попытки отправки, ключ меняется.
- Корзина очищается только при нажатии «Отправить заказ в WhatsApp». Автоматического перехода в WhatsApp нет.
- Если после успешного заказа страницу перезагрузили, экран подтверждения показывается снова (6 часов).
- Кнопка «Назад» на Android закрывает открытую шторку, а не уходит со страницы.
- Время готовности считается по часовому поясу заведения (`hours.tz`), а не по часовому поясу телефона.

## Что проверить вместе с бэкендом (`VERIFY`)

1. **Последний слот.** Сайт предлагает слоты строго до закрытия (при закрытии в 23:00 последний — 22:45). Бэкенд должен считать так же, иначе последний слот получит `invalid_time`.
2. **Округление времени.** Слоты выровнены по сетке `slotMinutes` от полуночи (:00, :15, :30, :45) и начинаются не раньше «сейчас + `leadMinutes`». Бэкенду стоит давать запас 2–3 минуты на дорогу запроса.
3. **Turnstile и повтор.** При автоматическом повторе после обрыва связи отправляется новый токен с тем же `clientKey`. Бэкенд должен проверять `clientKey` на повтор **до** проверки токена или принимать повтор с новым токеном — тогда возвращается тот же заказ.
4. **Пустой токен.** Если Turnstile не загрузился за 25 секунд, заказ уходит с пустым `turnstileToken`, и решение принимает сервер (ответ `spam` с понятным `message`).
5. **Параметры Turnstile.** Используются `appearance: "interaction-only"`, `size: "flexible"`, `language: "ru"`, `action: "order"` — сверить с актуальной документацией Cloudflare.
6. **Редирект Apps Script.** На POST Apps Script отвечает 302 на `script.googleusercontent.com`; `fetch` идёт по редиректу, финальный ответ должен содержать `Access-Control-Allow-Origin: *`. Проверить на опубликованном скрипте.
7. **Beacon `opened`.** `navigator.sendBeacon` отправляет `text/plain`; Apps Script должен разбирать его тело так же, как тело заказа.
8. **Поле `now` (необязательно).** Если бэкенд добавит в ответ меню серверное время `now` (ISO), сайт будет поправлять неверные часы телефона. Без этого поля всё работает как раньше.
9. **Старые WebView без часовых поясов.** Если браузер не умеет `Intl` с часовыми поясами, сайт считает время как UTC+6 (Бишкек без перехода на летнее время).

## Проверка на телефоне (5 минут)

Откройте ссылку на сайт **из чата WhatsApp** на Android-телефоне:

- [ ] Лендинг открывается, логотип и фото на месте, цены вида `319с` в жёлтой плашке.
- [ ] После прокрутки сверху появляется шапка с кнопкой «Предзаказ».
- [ ] «Написать в WhatsApp» открывает чат с приветствием; «Открыть на карте» открывает карту.
- [ ] На странице предзаказа работают кнопки «Картофель» / «Хот-доги».
- [ ] Карточка открывает шторку: количество, топпинги с круглыми фото, сумма меняется сразу.
- [ ] Системная кнопка «Назад» закрывает шторку и не уходит со страницы.
- [ ] Корзина: меняется количество, позиция удаляется, итог верный.
- [ ] Телефон `0705515151` превращается в `+996 705 515 151`; неверный номер даёт понятную ошибку.
- [ ] Время показывается как «сегодня, 21:30» / «завтра, 12:00», первое выбрано.
- [ ] Без галочки согласия заказ не отправляется.
- [ ] Отправка: кнопка блокируется и крутится, затем экран «Заказ №…».
- [ ] «Отправить заказ в WhatsApp» открывает чат с готовым текстом заказа. Сообщение отправляется.
- [ ] В таблице заказ отмечен как «открыт в WhatsApp».
- [ ] Возврат назад из WhatsApp: экран подтверждения на месте, корзина пустая.
- [ ] Двойное быстрое нажатие «Оформить заказ» создаёт один заказ.
- [ ] Выключите в таблице одно блюдо — через 10 минут (или после перезагрузки) оно серое и не добавляется.
- [ ] Включите в таблице «закрыто» — появляется баннер с часами, меню видно, заказать нельзя.
- [ ] Откройте предзаказ, затем включите режим полёта и обновите страницу — меню всё равно видно, с пометкой о ценах.
